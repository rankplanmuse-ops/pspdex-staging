Base fee plus priority fee

Every Solana transaction pays a base fee of 5,000 lamports per signature, which is fixed and usually negligible. The variable part is the priority fee: you set a compute unit limit for the transaction and a price per compute unit in micro-lamports, and the product is added to your fee to bid for faster inclusion.

  • Base fee: 5,000 lamports per signature (0.000005 SOL)
  • Priority fee = compute units x micro-lamports per CU / 1,000,000
  • 1 SOL = 1,000,000,000 lamports; 1 lamport = 1,000,000 micro-lamports

A plain wallet transfer with one signature and no priority fee costs a fraction of a cent, which is why Solana is attractive for payments and point-of-sale. Priority fees only matter when you compete for contested state during congestion. New token accounts also require a recoverable rent-exempt deposit of roughly 0.002 SOL, separate from transaction fees.

Frequently asked questions

How are Solana fees calculated?
The base fee is 5,000 lamports per signature, and 1 SOL is 1,000,000,000 lamports. On top of that, a priority fee of compute units multiplied by the micro-lamport rate per compute unit can be added to compete for faster processing.
What is a lamport?
A lamport is the smallest unit of SOL, named after computer scientist Leslie Lamport. One SOL equals one billion lamports, so the 5,000 lamport base fee is 0.000005 SOL per signature.
When do I need a priority fee?
Simple wallet transfers rarely need one. Priority fees matter for time-sensitive actions during congestion, such as trading or minting, where many transactions compete for the same block space and state.
Are there other costs beyond the transaction fee?
Creating new token accounts requires a small rent-exempt deposit of about 0.002 SOL, which is recoverable when the account is closed. Merchants using a payment processor also pay the processor's percentage on top of the network fee.
